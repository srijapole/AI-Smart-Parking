# AI Smart Parking System

A web-based application to manage parking slots and reservations.

## Technologies Used
- HTML
- CSS
- JavaScript
- Python FastAPI
- Neon PostgreSQL

## Features
- User Registration and Login
- Parking Dashboard
- Available and Occupied Slots
- Book Parking Slot
- My Reservations
- Cancel Reservation
